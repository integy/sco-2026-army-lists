# SCO 2026 Army Lists

Standalone Warhammer 40,000 army-list browser for SCO 2026, King Crimson edition.

- 14 teams and 84 army lists
- Browse by team or faction
- Search and cross-filter army lists
- View full lists and compare up to three side by side
- Download a standalone HTML copy for offline use

## Website

https://integy.github.io/sco-2026-army-lists/

## Source

`index.html` is the unchanged `SCO_2026_Army_Lists.html` supplied in `SCO_2026_Army_Lists_HTML.zip`, renamed for GitHub Pages. No build step or external libraries are required.

To run locally:

```sh
python3 -m http.server 8000
```

Open http://localhost:8000.
